# บริบทและที่มาของโครงการ (BKK Careplan - Traffy Fondue Diaper Request)

## 1. ที่มาและวัตถุประสงค์ (Background & Objective)
โครงการยื่นคำร้องขอรับการสนับสนุนผ้าอ้อมผู้ใหญ่และแผ่นรองซับการขับถ่าย เป็นนโยบายร่วมระหว่าง **กรุงเทพมหานคร (กทม.)**, **สำนักงานหลักประกันสุขภาพแห่งชาติ (สปสช.)**, และ **ศูนย์เทคโนโลยีอิเล็กทรอนิกส์และคอมพิวเตอร์แห่งชาติ (NECTEC)** เพื่อให้ประชาชนกลุ่มผู้ป่วยติดเตียงและผู้มีภาวะกลั้นปัสสาวะ/อุจจาระไม่ได้ ในพื้นที่ 50 เขตของกรุงเทพมหานคร สามารถเข้าถึงสิทธิประโยชน์หลักประกันสุขภาพได้อย่างสะดวก รวดเร็ว และไม่มีค่าใช้จ่าย

โดยระบบเว็บฟอร์มนี้พัฒนาขึ้นเพื่อทำงานเป็น **Webview Integration ร่วมกับแอปพลิเคชัน Traffy Fondue** ช่วยให้ประชาชนและผู้ดูแลสามารถยื่นคำร้องผ่านโทรศัพท์มือถือได้อย่างรวดเร็ว ก่อนส่งต่อข้อมูลไปยัง **ศูนย์บริการสาธารณสุข (ศบส.) ทั้ง 69 แห่ง** ของกรุงเทพมหานคร เพื่อจัดส่งทีมพยาบาลเยี่ยมบ้านลงประเมินและอนุมัติการสนับสนุนต่อไป

## 2. การวิเคราะห์และจัดลำดับคำถามตามหลัก UX/UI (Information Architecture)
เพื่อให้ฟอร์มมีอัตราการกรอกสำเร็จ (Completion Rate) สูงที่สุด และลดความกังวลของผู้สูงอายุหรือผู้ดูแล ฟอร์มถูกออกแบบภายใต้หลักการดังนี้:

1. **Location-First Smart Auto-Fill:** 
   - กำหนดให้ปักหมุดแผนที่ GPS (Step 4) ก่อนการกรอกที่อยู่ (Step 5) เพื่อให้ระบบยิง Reverse Geocoding สกัดเอาชื่อ **แขวง** และ **เขต** มาเติมให้อัตโนมัติ ลดภาระการพิมพ์ 
2. **Auto-Fill BKK Address Autocomplete:**
   - ระบบค้นหาแขวง/เขต ใน กทม. รองรับการแตะเลือกทันทีเมื่อ Focus (Zero-Query Suggestion) และการเลือกจากตัวเลือกย้อนกลับ เพื่อป้องกันการพิมพ์ชื่อแขวงหรือเขตผิดพลาด 100%
3. **Progressive Disclosure & Conditional Logic:**
   - ถามเฉพาะข้อมูลที่จำเป็นและอยู่ในบริบทของผู้ใช้ ข้ามข้อ 11 (ข้อมูลผู้ดูแล) อัตโนมัติหากผู้ป่วยสามารถดูแลตัวเองได้
4. **Clean Single-Point Focus UI:**
   - รวมลำดับขั้นตอนไว้ในการ์ดคำถามเป็น `คำถามที่ X / 12` ช่วยให้ผู้ใช้โฟกัสจุดเดียวในการอ่านเนื้อหา
