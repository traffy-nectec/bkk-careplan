# คู่มือการสั่งงาน AI (AI Prompting & Engineering Guide)

คู่มือนี้จัดทำขึ้นเพื่อให้ทีมพัฒนาหรือผู้สนใจสามารถนำไฟล์เอกสารต้นฉบับ 3 ไฟล์ในโครงการ ไปใช้สั่งงาน AI Coding Assistant (เช่น Antigravity / Gemini / Claude) เพื่อสร้างเว็บฟอร์มยื่นเรื่องผ้าอ้อมผู้ใหญ่ที่มีคุณภาพ UX/UI และตรรกะระบบระดับสูงได้อย่างแม่นยำ

---

## 📂 1. เอกสารต้นฉบับอ้างอิงที่ต้องแนบให้ AI (Input Documents)

เมื่อเริ่มต้นบทสนทนากับ AI ให้แนบไฟล์อ้างอิงทั้ง 3 ไฟล์เข้าใน Context:
1. `docs/references/2.Diapers 01-2, 02 D3 16-12-2568.pdf` (หลักเกณฑ์และแบบประเมินทางการแพทย์ สปสช. / กทม. แบบ 01 และ 02)
2. `docs/references/ขั้นตอนการรับผ้าอ้อม Traffy Fondue4-8-2569_5pm.pdf` (ขั้นตอนกระบวนการรับเรื่องผ่าน Traffy Fondue)
3. `okf/module_bkk_careplan.md` (ข้อกำหนดทางเทคนิคและโครงสร้าง JSON Payload)

## 🎯 2. กรอบแนวคิด UX/UI และตรรกะระบบที่ต้องสั่ง AI (System Constraints & Principles)

เมื่อต้องการให้ AI ออกแบบระบบ ต้องระบุกรอบแนวคิดสำคัญ 5 ประการดังนี้:

1. **สถาปัตยกรรมข้อมูล 2 ระยะ (2-Stage Data Model):**
   * **Stage 1 (Citizen Form):** ฟอร์มสกรีนนิ่งของประชาชนบนมือถือ (12 ข้อคำถามย่อย) เน้นรวดเร็ว 3-5 นาทีจบ
   * **Stage 2 (In-Home Assessment):** ประเมินทางการแพทย์เชิงลึก (บัตรคนพิการ, ADL 10 ข้อ, ข้อระวัง) ให้แยกไว้สำหรับพยาบาล ศบส. กรอกตอนเยี่ยมบ้าน
2. **Location-First & Smart Auto-fill Pipeline:**
   * ให้เรียง **ข้อปักหมุดแผนที่ GPS (ข้อ 4)** ขึ้นก่อน **ข้อกรอกที่อยู่ (ข้อ 5)** เพื่อดึงค่า Reverse Geocoding สกัดเอา แขวง และ เขต มาเติมในที่อยู่อัตโนมัติ
3. **BKK Address Autocomplete (jquery.Thailand.js style):**
   * ช่องกรอกที่อยู่ต้องมีระบบพิมพ์ค้นหา/แตะเลือก แขวง/เขต/รหัสไปรษณีย์ ยอดนิยมของ กทม. ทันทีเมื่อ Focus (Zero-Query Suggestions) เพื่อป้องกันพิมพ์ผิด 100%
4. **Progressive Disclosure & Single-Point Focus UI:**
   * ลบการบอกลำดับข้อซ้ำซ้อนจาก Top Header ออกทั้งหมด ย้ายมาแสดงไว้ในการ์ดคำถามเป็น `คำถามที่ X / 12` จุดเดียว
5. **Accessibility สำหรับผู้สูงอายุ:**
   * มีปุ่มขยายขนาดตัวอักษร 3 ระดับ (`A`, `A+`, `A++`) ที่ Top Header

## 💬 3. ชุดคำสั่งสำเร็จรูป Master Prompt (Ready-to-use Master Prompt)

สามารถก๊อปปี้ข้อความด้านล่างนี้ ไปวางในช่องแชท AI ได้ทันที:

```markdown
ช่วยออกแบบและสร้าง Web Application ฟอร์มยื่นเรื่องขอรับสิทธิผ้าอ้อมผู้ใหญ่ กรุงเทพมหานคร ผ่าน Traffy Fondue (Webview) โดยใช้อ้างอิงจากไฟล์เอกสาร 3 ไฟล์ที่แนบมา:
1. `docs/references/2.Diapers 01-2, 02 D3 16-12-2568.pdf`
2. `docs/references/ขั้นตอนการรับผ้าอ้อม Traffy Fondue4-8-2569_5pm.pdf`
3. `okf/module_bkk_careplan.md`

โปรดปฏิบัติตามหลักการ UX/UI และตรรกะระบบดังต่อไปนี้:

1. [Data Architecture]: แยกข้อมูลเป็น 2-Stage Data Model 
   - Stage 1: ฟอร์มประชาชนบนมือถือ (12 ข้อคำถามย่อย) สกรีนนิ่งรวดเร็ว
   - Stage 2: ย้ายการประเมิน ADL 10 ข้อ, บัตรคนพิการ และข้อระวังทางการแพทย์ ไปไว้ให้พยาบาล ศบส. ประเมินตอนเยี่ยมบ้าน

2. [Information Architecture Pipeline]:
   - คำถามที่ 1: สถานะผู้กรอกข้อมูล (ผู้ป่วย / ญาติยื่นแทน)
   - คำถามที่ 2: สภาวะความเดือดร้อน (ติดเตียง / กลั้นไม่ได้) - Eligibility Filter
   - คำถามที่ 3: ขนาดไซส์ผ้าอ้อมผู้ใหญ่ที่ต้องการ (S, M, L, XL, ไม่แน่ใจ)
   - คำถามที่ 4: พิกัดสถานที่พักอาศัย GPS (Location-First) - ปักหมุดแล้วยิง Reverse Geocoding
   - คำถามที่ 5: ที่อยู่ กทม. + BKK Autocomplete (ค้นหาแขวง/เขต) + ช่องจุดสังเกตใกล้บ้าน (ไม่บังคับ)
   - คำถามที่ 6: ชื่อ-นามสกุล ผู้ป่วย
   - คำถามที่ 7: เลขบัตรประจำตัวประชาชน 13 หลัก (Auto-format + Thai ID checksum validation)
   - คำถามที่ 8: สิทธิการรักษาพยาบาลหลัก (บัตรทอง 30 บาท / ประกันสังคม / ข้าราชการ)
   - คำถามที่ 9: เบอร์โทรศัพท์ติดต่อนัดหมาย
   - คำถามที่ 10: สภาพการดูแลตัวเอง (หากเลือกดูแลตัวเองได้ ให้ข้ามข้อ 11 ให้อัตโนมัติ)
   - คำถามที่ 11: ข้อมูลญาติ/ผู้ดูแล (แสดงเฉพาะเมื่อต้องมีผู้ดูแล)
   - คำถามที่ 12: แนบรูปถ่ายประกอบ (รูปผู้ป่วย / ที่พัก / ใบรับรองแพทย์)
   - ขั้นตอนสุดท้าย (13): สรุปข้อมูลการยื่นเรื่องแบบ UX Structured Cards 4 หมวดหมู่ พร้อมปุ่มกดแก้ไขเฉพาะจุด

3. [UI Design & Micro-interactions]:
   - ใช้ Vanilla HTML5, CSS3 (Modern Glassmorphism & Soft Gradients), JavaScript ES6
   - ปรับขนาดตัวอักษรได้ 3 ระดับ (A, A+, A++) ที่มุมขวาบนของ Header
   - ใช้ Single-Point Focus UI แสดงคำถามในการ์ดเนื้อหาเป็น `คำถามที่ X / 12`
   - เมื่อกดส่งเรื่อง ให้แสดง Modal แสดง JSON Payload ตามโครงสร้างที่ระบุใน okf/module_bkk_careplan.md

4. [Slash Command Recommendation]:
   - สามารถใช้เทคนิคการคุยปรับแผนแบบ interactive โดยใช้คำสั่ง `/grill-me` เพื่อสัมภาษณ์เก็บรายละเอียดก่อนสร้างโค้ด
```

## 🛠️ 4. เคล็ดลับเพิ่มเติม (Tips & Best Practices)

* **ใช้ Slash Command `/grill-me`:** หากต้องการปรับแต่งเงื่อนไข หรือต้องการให้ AI ช่วยวิเคราะห์ฟอร์มตามหลัก UX แนะนำให้พิมพ์ `/grill-me` เพื่อให้ AI สัมภาษณ์และไล่เก็บความต้องการก่อนเริ่มลงมือเขียนโค้ด
* **ทดสอบฟังก์ชันบน Mobile Viewport:** ให้ AI ช่วยเขียนสคริปต์ Playwright ในการทดสอบและบันทึกภาพถ่ายหน้าจอมือถือ (Viewport 414x896) ครบทุกขั้นตอนเพื่อตรวจสอบความถูกต้อง
* **ตรวจสอบผลลัพธ์ JSON Payload:** ตรวจสอบเสมอว่า JSON Payload สอดคล้องกับ API Spec ของ Traffy Fondue และระบบ กทม. หลังบ้าน
